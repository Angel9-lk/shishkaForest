# Руководство по проекту

## Назначение

Проект предназначен для загрузки, нормализации и анализа сетевых потоков из набора CICIDS2017-DOS. Главная задача — выделить подозрительные записи на основе статистических границ выбросов и подготовить результаты для дальнейшего анализа.


1. Исходный CSV загружается в `staging_traffic`.
2. Создаётся временная таблица `staging_clean` с типизированными столбцами.
3. Заполняются справочники IP-адресов, протоколов и меток атак.
4. Данные переносятся в `traffic_flows`.
5. Квартильная статистика сохраняется в `feature_statistics`.
6. SQL-запрос сравнивает значения признаков с верхними границами IQR.
7. Для каждой записи рассчитываются флаги выбросов и `anomaly_score`.

## Алгоритм обнаружения

Для выбранного признака вычисляются первый квартиль `Q1`, третий квартиль `Q3` и межквартильный размах:

```text
IQR = Q3 - Q1
Верхняя граница = Q3 + 1.5 × IQR
```

В текущем запросе проверяются:

- `flow_duration`;
- `total_fwd_packets`;
- `total_backward_packets`.

Итоговая классификация:

| Балл | Результат |
|---:|---|
| 0 | Норма |
| 1 | Требует проверки |
| 2–3 | Аномалия |

Важно: статистический выброс не является доказательством атаки. Результат нужно сопоставлять с `dataset_label`, IP-адресом, портом, протоколом и другими признаками потока.

## Основные таблицы

| Таблица | Назначение |
|---|---|
| `traffic_flows` | Нормализованные сетевые потоки |
| `staging_traffic` | Промежуточная загрузка исходных данных |
| `ip_addresses` | Справочник IP-адресов |
| `protocols` | Справочник сетевых протоколов |
| `attack_labels` | Метки классов и атак |
| `feature_statistics` | Статистические границы признаков |
| `whitelisted_ips` | Белый список доверенных IP |

## SQL-файлы

- `Создание базы данных и внесение данных.sql` — подготовка схемы и перенос данных.
- `Поиск аномалий.sql` — расчёт выбросов и итоговой классификации.
- `Аналитический запрос №1.sql` — подсчёт общего количества потоков и атак.
- `Аналитический вопрос №2.sql` — анализ источников и типов атак.
- `INSERT-запросы.sql` — примеры добавления записей и тестовой атаки.

##  Excel-файлы

Подготовленные рабочие копии находятся в каталоге `excel/`:

- `begin.xlsx` — границы IQR для `Flow Duration`;
- `analysis_results.xlsx` — результаты поиска аномалий и сводка;
- `quartiles.xlsx` — квартильная статистика признаков.
