# Структура и файлы проекта

## Назначение

Проект анализирует сетевой трафик из CICIDS2017-DOS и ищет статистически подозрительные потоки. В репозитории находятся исходные данные, SQLite-база, SQL-запросы, Excel-выгрузки, отчёты и презентация.

## Каталоги

### `data/`

Исходные материалы:

- `CICIDS2017-DOS (PB).csv` — исходный CSV-датасет сетевого трафика;
- `begin.xlsx` — Excel-файл с расчётом статистики по `Flow Duration`.

### `проект/`

Основные результаты работы:

- `SQLite С ВИВАМИ)).db` — рабочая SQLite-база;
- `export from sqliteonline.com(1).xlsx` — выгрузка результатов поиска аномалий;
- `quartiles [93VZVO].csv` — квартильные значения признаков;
- `ОТЧЕТ ПО П27-28.docx` и копия — отчёты;
- `отчет 1.pdf` — PDF-версия отчёта.

### `sql/`

Основные SQL-скрипты базы:

- создание промежуточной таблицы и перенос данных;
- вставка тестовых записей;
- поиск аномалий;
- аналитика по потокам и источникам атак.

### `excel/`

Рабочие копии Excel-документов:

- `begin.xlsx`;
- `analysis_results.xlsx`;
- `quartiles.xlsx`;
- `README.md`.

### `docs/`

Краткая навигация и руководство пользователя.

### `presentation/`

`ПРЕЗА.pptx` — презентация проекта.

        v
